# ml-lab

My 26-week path to AI/ML Engineer: Python and math, classical ML, deep learning with PyTorch, LLM fine-tuning, LLM apps, and MLOps. One folder per week, each with a notebook and a working build.

| Phase | Weeks | Focus |
|---|---|---|
| 1 | 1-4 | Python, NumPy, pandas, linear algebra, probability |
| 2 | 5-8 | Classical ML with scikit-learn and XGBoost |
| 3 | 9-13 | Deep learning with PyTorch, GPT from scratch |
| 4 | 14-17 | Hugging Face, LoRA fine-tuning, Somali-language model |
| 5 | 18-21 | RAG, agents, evals, FastAPI |
| 6 | 22-26 | MLOps: tracking, Docker, CI/CD, cloud, monitoring |

Run locally: `uv sync` then `uv run jupyter lab`.
